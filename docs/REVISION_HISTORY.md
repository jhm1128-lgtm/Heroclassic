# 버전 보관 내역

REV.40 원본은 저장소 루트에 보존되어 있습니다. REV.41~50 원본은 현재 확보되지 않았습니다.

## REV.51

기본 특수지역 종료 관찰 및 일반사냥 복귀 흐름 개선.

## REV.52

이벤트 특수지역 입장 준비 흐름 개선.

## REV.53

예약 UI 정리 및 중복 예약 시작 조작 정리.

## REV.54

대시보드 재구성, 양쪽 상태 동시 표시, 자동화 버튼 상태 표시 및 캐릭터별 층 설정.

## REV.55

이벤트 진입 전 현재 사냥 화면 판단, 메뉴 열기 및 입장 재시도 개선.

## REV.56

이벤트 종료 시 게임 자체 일반사냥 복귀를 확인하고 AUTO만 복구. 주기적인 창 활성화 제거.

## REV.57

출석 팝업의 제목·내용·닫기 버튼을 확인하고 닫힌 상태를 재확인.

## REV.58

기본 특수지역 종료 후 한밭마을 판단 및 다음 지역 연결 개선.

## REV.59

관찰을 가리는 게임 메뉴·지도 등을 정리하고 HUD 재확인.

## REV.60

Telegram 연결 설정, 5분 지연 경고 및 해소 알림 추가. 화면 가림 경고 문제는 V61에서 수정.

## REV.61

가림·비활성·최소화로 관찰할 수 없는 동안 Telegram 경고를 보류하고 재관찰 시 기준 시간 초기화.

## REV.62

GUI 트레이 아이콘, 최소화·복원·상태 표시·종료 구현.

REV.51~52는 보존 소스 재압축본입니다. REV.53~62는 기존 배포 ZIP이며 과거 버전의 알려진 문제도 그대로 포함합니다. 실제 사용은 최신 REV.62를 기준으로 합니다.

## REV.63

버려진 동굴 선택 후 달라지는 카드 이름의 인식 보완. 선택 확인 후 1층 클릭 없이 입장·확인·AUTO 확인으로 연결합니다. 다른 이벤트의 층 선택은 유지합니다.

## REV.64

버려진 동굴 사냥 중 GUI 재시작 시 미니맵 실제 지역명과 남은시간을 확인해 AUTO·이벤트 관찰을 이어받습니다. 수동 특수지역 클릭도 해당 이벤트 관찰로 위임합니다. 이벤트 안내 시간만으로 입장을 추정하지 않습니다. 추가된 이어받기 위치 인식은 버려진 동굴 대상입니다.

## REV.65

미니맵 지역명 전체 글자의 마스크를 비교해 움직이는 배경에 따른 버려진 동굴 인식 실패를 보완했습니다. 시간제 사냥 중 지역이 불분명하면 현재 사냥을 유지하면서 노출된 HUD만 확인하고 재입장·주기적 창 전환을 반복하지 않습니다. 실제 이벤트 위치에서 AUTO OFF 글자를 확인하면 주변 HUD 그림 인식 실패에도 OFF 글자 좌표로 켠 뒤 ON을 확인합니다.

## REV.66

현재 월드지역 목록의 저주받은 니조성 전체 이름 글자 템플릿을 추가했습니다. 기존 템플릿 크기·배경 차이로 인식이 실패해 카드 선택 없이 목록 검색을 반복하던 문제를 보완합니다. 실제 맨 위 대상 카드를 확인해 클릭하고, 선택·월드탭·1층 확인 후 입장합니다.

## REV.67

자동화 시작 시 AUTO만 확인하고 진행 관찰을 이어받지 못하던 흐름을 보완했습니다. 기본 특수지역 안이면 종료 관찰 재개를 요청하고, 05:01 이후 확인된 한밭마을이면 남은 지역 검사→모두 만료 시 일반사냥으로 연결합니다. 이미 일반사냥 중이면 유지하고, 이벤트 진행은 기존 예약 흐름을 유지합니다. 미확인 화면·예약 시각 전 마을·중지·연결 변경에는 임의 이동을 요청하지 않습니다.

## REV.68

결제 후 실제 이벤트 위치·남은시간 또는 AUTO OFF 표시가 확인되는 경우도 도착 판정과 AUTO 확인으로 연결합니다. 입장 후 도착 확인이 지연됐다는 이유로 강제 일반사냥 복구를 실행하던 경로를 제거했습니다. 결과 불명확 시 재입장·추가 결제·강제 이동 없이 현재 상태를 재확인합니다. 남은 일반사냥 복구 작업은 실제 버려진 동굴 사냥을 확인하면 취소하고 이벤트 관찰로 넘깁니다. 종료는 자연 복귀·AUTO 확인 방식입니다.


## REV.69

가덕도왜성 선택 후 이름 그림의 배경 차이로 인식 점수가 낮아져 floor 확인이 만료되던 문제를 보완했습니다. 전체 이름 글자 템플릿을 추가했고 선택 테두리·특수지역 탭·1층 확인 조건과 기존 기준은 유지합니다. V68을 포함한 누적 전체 적용본입니다.


## REV.70

단일 층인 가덕도왜성의 1층 클릭을 생략했습니다. 지역 선택→입장→확인→AUTO 확인으로 연결합니다. 버려진 동굴도 층 클릭 생략을 유지하며 니조성 층 선택은 유지합니다. 선택 지역·테두리·탭·1층 표시·입장 확인창 검사는 유지합니다. V69 포함 누적 전체 적용본입니다.


## REV.71

자동화를 다시 켤 때 한밭마을/일반사냥 위치를 확인했는데 이전 이벤트 입장 기록이 남아 현재 이벤트 진입을 차단하던 문제를 보완했습니다. 해당 이벤트의 이전 예약·종료·대기 상태를 정리해 현재 시각 이벤트를 다시 예약합니다. 실제 특수지역 사냥/불명확 화면은 기록을 유지합니다. V70 포함 누적 전체 적용본입니다.


## REV.72

자동화 카드의 대기/최소화/Telegram 상태 설명 라벨을 제거했습니다. 자동화·Telegram 설정 버튼과 기능은 유지합니다. 입장 층 요약은 첫 세 지역과 마지막 두 지역을 두 줄로 나눠 조선왕릉 2층이 분리되지 않게 정리했습니다. 층 설정 변경에도 같은 형식을 적용합니다. 사냥·예약 로직은 V71과 동일합니다.
