왼쪽 게임을 켜지 않고 오른쪽 게임 하나만 실행해도 자동화가 시작됩니다. 왼쪽 메뉴·층 설정·예약 기능은 그대로 남아 있습니다.

적용 순서
1. 기존 GUI를 완전히 종료합니다. 트레이에 있다면 프로그램 종료를 선택합니다.
2. 이 ZIP 전체를 기존 설치 폴더에 덮어씁니다. hunting_floors.json, telegram_alerts.json 등 개인 설정은 보존합니다.
3. 오른쪽 캐릭터 게임만 실행하고 GUI를 다시 켭니다.
4. 처음 연결하는 게임 창이 하나이면 오른쪽 캐릭터에 자동 연결합니다. 오른쪽 설정 탭에서 연결된 창을 확인합니다.
5. 오른쪽 자동화 또는 기존 2분할 자동화 버튼을 켭니다. 오른쪽 자동화는 녹색, 왼쪽은 대기 상태로 둡니다. 전체 버튼은 한쪽 켜짐으로 녹색 표시됩니다.

변경 사항
- 전체 자동화의 게임 창 2개 필수 조건을 제거했습니다. 실제 연결되어 화면 위치를 확인할 수 있는 게임만 예약을 시작합니다.
- 게임 하나의 최초 자동 연결은 선택된 탭과 무관하게 오른쪽을 기본으로 합니다. 이미 연결된 게임의 좌우 소속은 탭 변경으로 바꾸지 않습니다. 왼쪽 하나를 명시적으로 연결한 경우에는 그 연결을 존중합니다.
- 없는 왼쪽 창은 예약/시작 상태 확인 작업을 등록하지 않습니다. 오른쪽의 새벽 보급, 기본 특수지역, 일반사냥 및 이벤트 예약은 기존 오른쪽 설정을 사용합니다.
- 양쪽 게임을 연결한 경우 기존 양쪽 자동화를 유지합니다. 개별 On/Off 및 Esc 전체 중지도 유지합니다.
- GUI를 켠 시점에 이미 지난 04:50 보급을 소급 실행하지 않는 기존 규칙은 유지합니다. 보급부터 즉시 시작하려면 오른쪽 START를 사용합니다.
- 오른쪽 일반사냥 목적지는 기존 대한해협 왜구 함선1 내부입니다. 게임 내부 화면은 800x600을 유지합니다.

검증: 실제 게임 입력 없이 오른쪽 게임만 존재하는 최초 연결/전체 및 개별 시작 조건, 왼쪽 닫힘, 탭 변경 시 연결 유지, 명시적 왼쪽 단독 연결, 양쪽 연결, 창 없음/중복 연결 거부, 오른쪽 04:50 보급 -> 보급 완료 -> 05:01 특수지역 예약, 이벤트 예약 켜기를 모의 검사했습니다.
실제 V78 적용 후 오른쪽 단독 장시간 사냥 및 전체 예약 순환은 사용자 PC에서 추가 확인이 필요합니다.
