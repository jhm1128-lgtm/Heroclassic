1. 대시보드의 왼쪽/오른쪽 캐릭터 카드에 각각 자동화 On/Off 버튼을 추가했습니다.
- 켜짐은 녹색, 끔은 빨간색, 실행 전 대기는 기본색입니다.
- 해당 캐릭터를 끄면 그 캐릭터의 예약·대기·진행 조작만 중지합니다. 다른 캐릭터의 진행과 예약은 유지합니다. 게임 자체 AUTO는 끄지 않습니다.
- 전체 2분할 자동화 버튼과 Esc 전체 중지는 기존대로 유지합니다. 개별 켜기는 현재 시각·상태 확인 후 예약을 재개하며 지난 04:50 보급을 소급 실행하지 않습니다.
2. 부패한 도성 5시간 충전 화면에서 배경 차이로 시간 그림 비교가 실패하던 문제를 보완했습니다.
- 상세 시간 단위는 글자 마스크로도 확인하고, 실제 부패한 도성 카드 시간 단위 자산을 추가했습니다.
- 숫자 4/5를 특정 값으로 제한하지 않습니다. 숫자 OCR 대신 시간·분 단위, 카드의 유효 시간, 만료 표시의 관계를 확인합니다.
- 기본시간 만료와 충전시간 있음이 함께 보이는 경우에도 양쪽 시간 근거를 확인해 설정 층→입장→확인으로 진행합니다.
- 추가 충전 사냥 종료 후 한밭→다른 특수지역 재검색 없이 일반사냥·AUTO 연결은 유지합니다.
3. 사용자 요청에 따라 오른쪽 일반사냥 목적지는 기존 대한해협 왜구 함선1 내부로 유지합니다. 함선2 선택 기능은 추가하지 않았습니다.
