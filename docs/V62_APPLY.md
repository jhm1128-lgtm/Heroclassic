GUI 트레이 아이콘
GUI 창의 최소화(-) 버튼을 누르면 작업표시줄 대신 시계 옆 트레이로 들어갑니다.
트레이 아이콘이 바로 보이지 않으면 시계 옆 숨겨진 아이콘(^)을 확인하세요.
아이콘 더블클릭: GUI 다시 열기.
아이콘 우클릭: GUI 열기 / 자동화 및 좌우 현재 상태 확인 / 프로그램 종료(자동화 중지).
아이콘 녹색=양쪽자동화 켜짐, 빨강=꺼짐, 회색=대기, 주황=한쪽만 켜짐.
GUI의 X는 트레이 숨김이 아니라 실제 프로그램 종료입니다.

백그라운드 동작
트레이에 숨겨도 예약·진행 관리·Telegram 감시는 계속 실행됩니다.
트레이 메뉴는 별도로 처리하여 메뉴가 열린 동안 GUI 타이머를 막지 않습니다.
게임 창 자체를 최소화해도 되는 기능은 아직 추가하지 않았습니다. 게임 화면 관찰 조건은 기존과 같습니다.
Telegram은 V61처럼 다른 프로그램에 가려진 게임을 오류로 알리지 않습니다.

적용
기존 GUI를 X로 종료 → V62 ZIP 전체 C:\Game 덮어쓰기 → 실행.
hunting_floors.json과 telegram_alerts.json은 보존하세요.
좌우 연결 확인 → 2분할 자동화 녹색. 현재 특수지역 사냥 중이면 각 탭 특수지역 한 번씩으로 관찰 재개.
현재 일반사냥 중이면 자동화 녹색으로 예약 대기합니다. 이후 GUI 최소화(-)로 트레이에 넣으면 됩니다.
트레이 등록 실패 시 창을 숨기지 않고 일반 최소화로 사용할 수 있게 남깁니다.
업데이트 때는 트레이 우클릭의 프로그램 종료를 사용해 기존 GUI를 완전히 종료하세요.

검증
실제 Windows 트레이 등록/아이콘상태변경/GUI 최소화와복원3회/더블클릭및메뉴요청/숨김중타이머유지/종료시정리 검사를 통과했습니다.
초기구현에서발견한GUI메시지충돌을수정하여트레이처리를별도스레드로분리했습니다. 최종검사에서Tk콜백오류0을확인했습니다.
등록실패시창이사라지지않는대체동작과기존Telegram설정창도검사했습니다.
검사중기존게임에입력하거나실제Telegram메시지를보내지않았습니다. V62실게임예약진행은적용후확인하면됩니다.
