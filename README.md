# Heroclassic

HeroOfChosunClassic 두 캐릭터 사냥 일정 관리 GUI입니다. Windows의 800×600 게임 창 두 개를 대상으로 합니다.

## 최신 버전: REV.64

- [V64 전체 적용 ZIP 다운로드](https://github.com/jhm1128-lgtm/Heroclassic/raw/refs/heads/main/releases/EVENT-RESUME-20261021-64.zip)
- [V64 적용 방법](docs/V64_APPLY.md)
- [버전별 파일](releases/) · [변경 내역](docs/REVISION_HISTORY.md) · [검증 현황](docs/VALIDATION.md)

최신 소스와 화면 인식용 자산은 V64 ZIP에 모두 포함되어 있습니다.

V64: 버려진 동굴 사냥 중 GUI 재시작 시 실제 위치를 확인하여 재입장 없이 AUTO 확인과 이벤트 종료 관찰을 이어받습니다. V63의 선택 인식과 층 클릭 생략도 포함합니다.

GUI 최소화 시 트레이로 이동합니다. 트레이 더블클릭으로 복원하고, 우클릭으로 상태 확인 및 종료할 수 있습니다. GUI의 X는 실제 종료입니다.

## 실행 및 업데이트

1. Windows에서 Python 3.11과 Tkinter, `numpy`, `Pillow`가 필요합니다. 개발·검증 환경은 Python 3.11 32비트입니다. 의존성은 `python -m pip install -r requirements.txt`로 설치합니다.
2. 기존 GUI를 완전히 종료합니다. 트레이에 있다면 우클릭 → 프로그램 종료를 선택합니다.
3. 전체 ZIP을 기존 설치 폴더에 풀어 적용합니다. 기존 `hunting_floors.json`, `telegram_alerts.json`은 보존합니다. 각 ZIP은 누적 전체 적용본입니다.
4. `chosun_gui.py`를 실행하고 Windows 관리자 권한 요청을 승인합니다. 왼쪽·오른쪽 게임 연결을 확인하고 **2분할 자동화**를 녹색으로 켭니다.
5. 이미 기본 특수지역에서 사냥 중이라면 각 캐릭터 탭의 **특수지역**을 한 번씩 눌러 관찰을 재개합니다. 일반사냥 중이면 자동화 켜짐 상태로 예약을 기다립니다.

## 주요 기능

- 좌우 캐릭터별 일정과 입장 층 설정, 조작이 필요한 작업의 순차 실행.
- 04:50 복자할매·주모 보급 → 05:01 남은 기본 특수지역 → 일반사냥.
- 설정된 이벤트 시간에 특수지역 참가. 이벤트 종료 후 게임의 일반사냥 복귀를 확인하고 AUTO를 확인합니다.
- 수동 START / 상점창고 / 특수지역 / 일반사냥, 양쪽 현재 진행 표시.
- Telegram 지연 알림 및 트레이 실행. Telegram 봇 토큰·채팅 ID는 GUI에서 직접 설정합니다.

게임 창 자체의 최소화 동작과 4개 창 자동화는 구현 범위에 포함되지 않습니다. GUI를 최소화하는 것은 가능합니다. 가려진 게임은 관찰을 보류하며, V61 이후 Telegram이 화면 가림만으로 경고하지 않습니다.

## 보관 범위

기존 **REV.40 원본 ZIP은 그대로 보존**했습니다. 현재 확보된 **REV.51~64**를 추가했습니다. REV.51~52는 보존된 해당 버전 소스를 재압축했으며, REV.53~64는 기존 배포 ZIP입니다. REV.41~50은 원본을 확보하지 못해 포함하지 않았습니다.

`releases/manifest.json`에 각 추가 ZIP의 크기, SHA-256, 파일 수와 출처를 기록했습니다. 개인 설정·Telegram 인증 정보·실행 진단 자료는 배포에 포함하지 않습니다.
